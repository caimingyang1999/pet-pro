## AI 文章生成（端到端打通：Node 生成 → 后端落库草稿 → 后台一键生成）

- **后端（ruoyi-ai 模块，新增）**：
  - `AiArticleConfig`：读 `ai.article.{base-url,generate-path,status-path}`（yml 已加，默认同 3300）；
    `aiArticleWebClient` 带 120s 响应超时。
  - `ArticleGenerateRequest` / `ArticleGenerateResult`（含 Data/CoverImage/InlineImage 嵌套）DTO。
  - `IAiArticleService` + `AiArticleServiceImpl`：调 Node `/api/article/generate`，
    base64 配图经 `FileUtils.writeBytes(bytes, RuoYiConfig.getUploadPath())` 转存为 `/profile/...`，
    把正文 `__ARTICLE_IMG_n__` 占位符替换为真实地址，文章落库 **草稿(status=0)**（不自动发布）。
  - `AiArticleController`：`POST /api/v1/admin/articles/generate`（权限 article:add）+
    `GET /api/v1/admin/articles/generate/status`（能力探测）。
  - 注意：文章生成接口在 ruoyi-ai，但前缀与后台文章管理一致，复用 article:add 权限。
- **后台前端（ruoyi-ui）**：`article/index.vue` 加「AI 生成」按钮 + 对话框（宠物/分类/选题/配图开关/配图数），
  成功后直接打开草稿编辑框供人工审核发布；新增 API `generateArticle`/`getArticleGenerateStatus`（120s 超时）。
- **Node 服务（models-server，上轮已完成）**：`/api/article/generate` 生成文章+base64配图，
  配图优先硅基流动 AI、无 key 时回退 `public/article-lib/类型-序号.png`。
